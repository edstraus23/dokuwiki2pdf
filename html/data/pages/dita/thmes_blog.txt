====== Using Custom Themes for DITA-OT PDF Publishing ======

{{:dita:dita_ot_theme.jpeg?400|}}

Create professional PDFs from DITA source files without complex XSL-FO stylesheets. Modern DITA Open Toolkit (DITA-OT) versions let you define custom PDF styling with clean, readable YAML theme files.

Here is how to structure a custom theme and build your publication with DITA-OT.

====== 1. Define Your Custom Theme ======

Instead of modifying core plugin files, inherit default styles using extends: default and override only the elements you need to customize—such as brand colors, fonts, cover page layout, and headings. Find a sample theme at this path:

<code>
~/dita-ot-4.4/docsrc/samples/themes/dita-ot-docs-theme.yaml
</code>

Below is my modified theme, updated to use a sans-serif body font, remove the chapter-level TOC, add a custom logo, and enable title numbering.

<code yaml>
extends: default # Automatically inherits all default DITA-OT styles

# Global text styling definitions
ot-default:
  font-family: "Helvetica" 
  color: "#222222"

brand:
  color:
    inverse: '#e9ecef'
    links: '#3563ab'
    note:
      background:
        attention: '#fff3cd'
        caution: '#f8d7da'
        info: '#dce4f0'
        tip: '#d1e7dd'
    primary: '#1d365d'
    secondary: '#6c757d'
    tertiary: '#bac8d1'
    xml-domain: '#639'
# ↑ end-brand-colors ↑

# ↓ add-font-stacks ↓
pdf2:
  font:
    monospaced: 'Courier New, Courier, Arial Unicode MS, Tahoma, Batang, SimSun'
    sans: 'Helvetica, Arial Unicode MS, Tahoma, Batang, SimSun'
    serif: 'Times New Roman, Times, Arial Unicode MS, Tahoma, Batang, SimSun'
# ↑ end-font-stacks ↑
# Block specific modifications
style:
  body:
    font-family: $pdf2-font-sans
    font-size: 10pt
    line-height: 1.3
    start-indent: 50pt
  chapter:
    border-after: solid 2pt $brand-color-inverse
  note:
    background-color: "#f5f5f5"
    border-left: "3pt solid #ffcc00"
    padding: 6pt

  cover:
    # Path to the image relative to the theme file
    background-image: eds_logo.svg  
    background-repeat: no-repeat
    # Position the background graphic
    background-position: center          
    # Forces the cover block to span a specified height
    height: 25.7cm                       
  cover-title:
    color: "#1A365D"                     # Hex or predefined brand color variable
    font-family: sans-serif
    font-size: 36pt
    font-weight: bold
    line-height: 1.2
    text-align: center
    # Controls vertical placement on the page using XSL-FO spacing
    space-before: 12cm                   
    space-after: 0.5cm

  cover-titlealt:
    # Styles the subtitle or alternative title (DITA-OT 4.2+)
    color: "#4A5568"                     
    font-family: sans-serif
    font-size: 18pt
    font-weight: normal
    space-before: 0.2cm

  cmdname:
    color: $brand-color-primary
    font-weight: bold
  codeblock:
    background-color: $brand-color-inverse
    border: solid 1pt $brand-color-tertiary
    font-family: $pdf2-font-monospaced
    font-size: 8pt
    keep-together.within-page: always
    space-after: 8pt
  codeph:
    color: $brand-color-secondary
  example-title:
    color: $brand-color-secondary
  fig:
    caption:
      color: $brand-color-secondary
      font-size: 9pt
      font-style: italic
      font-weight: normal
  filepath:
    color: $brand-color-secondary
  h1:
    color: $brand-color-primary
    font-size: 18pt
    font-weight: bold
    padding-top: 0pt
    space-after: 9pt
    space-before: 0pt
    title-numbering: true
  h2:
    color: $brand-color-primary
    font-size: 16pt
    font-style: italic
    space-after: 8pt
    space-before: 16pt
    title-numbering: true
  h3:
    color: $brand-color-primary
    font-size: 14pt
    font-weight: bold
    space-after: 7pt
    space-before: 21pt
    title-numbering: true
  h4:
    font-size: 12pt
    font-style: italic
    space-before: 12pt
    title-numbering: false
  index:
    border-after: solid 2pt $brand-color-inverse
    color: $brand-color-primary
    font-family: $pdf2-font-sans
  li:
    label:
      color: $brand-color-secondary
  link:
    color: $brand-color-links
  note:
    attention:
      background-color: $brand-color-note-background-attention
    background-color: $brand-color-note-background-info
    border: solid 1pt $brand-color-tertiary
    caution:
      background-color: $brand-color-note-background-caution
    end-indent: '6pt + from-parent(end-indent)'
    important:
      background-color: $brand-color-note-background-attention
    keep-together.within-page: always
    label:
      font-family: $pdf2-font-sans
      space-end: 2pt
    notice:
      background-color: $brand-color-note-background-attention
    padding-end: 6pt
    padding-start: 6pt
    restriction:
      background-color: $brand-color-note-background-attention
    space-after: 12pt
    space-before: 6pt
    start-indent: '6pt + from-parent(start-indent)'
    tip:
      background-color: $brand-color-note-background-tip
    warning:
      background-color: $brand-color-note-background-caution
  option:
    color: $brand-color-secondary
    font-family: $pdf2-font-monospaced
    font-weight: bold
  parmname:
    color: $brand-color-primary
    font-family: $pdf2-font-monospaced
    font-weight: bold
  section-title:
    color: $brand-color-secondary
  shortdesc:
    color: $brand-color-secondary
    font-size: 12pt
    line-height: 1.3
  table:
    caption:
      color: $brand-color-secondary
      font-size: 9pt
      font-style: italic
      font-weight: normal
    font-family: $pdf2-font-sans
    font-size: 9pt
    header:
      background-color: $brand-color-inverse
  varname:
    color: $brand-color-secondary
    font-family: $pdf2-font-monospaced
    font-style: italic
    font-weight: bold
  xmlatt:
    color: $brand-color-xml-domain
  xmlelement:
    color: $brand-color-xml-domain
  xmlnsname:
    color: $brand-color-xml-domain
</code>


====== 2. Build Your PDF Using the Theme ======

Once your theme file is ready, pass it directly to the DITA-OT CLI using the ''--theme'' parameter:

<code Bash>
~/dita-ot-4.4/bin/dita \
  --input=blogs.ditamap \
  --format=pdf2 \
  --output=out \
  --theme=topics/my_theme.yml
</code>

Here's a sample bookmap:

<code xml>
