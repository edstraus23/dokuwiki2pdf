====== Using Metasploitable 2 and Kali Linux for Security Assessments ======


Setting up a local penetration testing lab using Docker involves creating a shared network, running a Metasploitable 2 target container, and launching a Kali Linux container to execute security assessments.

===== Initial Network and Container Setup =====

Create a custom Docker network:
''docker network create pentest''

Run Metasploitable 2:
<code bash>
docker run -it --name=metasploitable2 --net=pentest tleemcjr/metasploitable2 /bin/sh
</code>

Run with host network: Use docker run --network host -it tleemcjr/metasploitable2:latest sh -c "/bin/services.sh && bash" so the container shares your local network stack.Start internal services: Once inside the container shell, type services.sh to boot up the vulnerable daemons.

Run Kali Linux:
<code bash>
docker run -it --name=kali --net=pentest kalilinux/kali-rolling /bin/bash
</code>
